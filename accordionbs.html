HTML (HyperText Markup Language) is used to create the basic structure of a website. It defines elements such as headings, paragraphs, images, buttons, links, and sections.

CSS (Cascading Style Sheets) is used to style and design web pages. It controls colors, fonts, spacing, layouts, backgrounds, animations, and responsive designs.

JavaScript is a programming language used to make websites interactive and dynamic. It can handle clicks, forms, animations, sliders, menus, and other user interactions.
